# Changelog

## 0.2.0 - 2026-07-12

- Rebuilt the repository as a compact, parentless research-only public root.
- Preserved the 26 public synthetic cases, 52 fixture traces, schema `0.1.6`,
  deterministic scorer, Replay Ledger export, and nine hard gates.
- Removed development handoffs, planning and application framing, operator and
  infrastructure runbooks, nested release snapshots, and duplicate tarballs.
- Removed the non-standalone canonical-suite adapter and its external sibling
  validator dependency.
- Added machine-readable public-tree and full-history guards.
- Added a deterministic, allowlisted Hugging Face package builder and validator.
- Added CI for lint, tests, self-check, wheel build, public-boundary checks, and
  Hugging Face staging validation.
- Condensed the prior held-out-publication incident into a public-safe
  transparency note while retaining fail-closed release controls.

No public case, fixture, route expectation, or scorer behavior changed in this
release.

## Earlier development releases

The pre-0.2 development lineage is retained in a private archival repository.
It is not part of the public source history because those snapshots mixed
research artifacts with local operational and project-planning material.
